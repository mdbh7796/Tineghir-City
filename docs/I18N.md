# i18n strategy (Phase 1: infra)

- Dictionaries: `src/templates/i18n/{en,fr,ar}.json` (EN = reference).
- `npm run i18n:check` enforces key parity + `ar.dir === "rtl"`.
- `base.html` ships `hreflang="en|fr|ar|x-default"` alternates (same URL for now).
- Phase 2 (not yet): translate `index` + `practical` to FR first, then split
  output to `/fr/*.html` with `og:locale` + `<html lang>` per locale.
- Rule: add keys to `en.json` first, then FR/AR.
